The seam is the surface

Admin software is the vector

The most sensitive internal material often lives outside the core product — in the ordinary business tools every company shares. A frontier model can be perfectly guarded while the software around it is not.

Agents compose authority

An agent does not need a single powerful credential. It needs a path: one reachable affordance after another, each legitimate on its own, until the combination is not. That is the attack to test for.

Annual testing can’t keep up

Point-in-time assessments go stale the week a new integration ships. Agent-driven testing re-runs as the environment changes, so the map stays current with the system it describes.

How an engagement runs

01

Scope, in writing

Written authorization first. Rules of engagement, target systems, and off-limits systems are named in advance. Anything outside the signed scope is not tested.

02

Map

Autonomous agents enumerate reachable affordances across administrative software and integrations, and chain them into candidate paths — the same composition an adversary would attempt.

03

Validate, with a human gate

Paths are proven by execution, not theorized. Any consequential action pauses for human review before it proceeds. The agent proposes; a person disposes.

04

Disclose, completely

Full findings with a complete activity ledger: every path attempted, every system touched, every action taken, every source resolving to bad-guy.ai. Partial disclosure is a failed engagement — the client must be able to reconstruct everything we did.

What we will not do

  • No unattributable traffic. If you can’t identify it as us in your own logs, we don’t send it.
  • No testing without written authorization. No exceptions, no implied permission.
  • No scope creep. If it is not in the signed rules of engagement, it is not touched.
  • No partial disclosure. The client sees everything we did, including what failed.
  • No data retention beyond the engagement. Findings stay with the client; access ends when the engagement ends.
